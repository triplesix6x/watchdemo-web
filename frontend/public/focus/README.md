# Focus hero assets

`app-home.webp` and `app-home-mobile.webp` are color studies derived from the existing WatchDemo library screenshot through `docs/design-review/build.py`. The mobile image is a crop of the same original. Match names, players, events, scores and application content were not replaced. They are not new captures of the updated native desktop build.

The original six files in `public/screens/` remain unchanged. `contours.svg` is the static accessibility/no-WebGL fallback from the approved Focus prototype, not a replacement for the interactive renderer.

Interactive Topography is adapted from [React Bits](https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Backgrounds/Topography). Its full MIT + Commons Clause terms and copyright notice are distributed with this website in `Topography-LICENSE.txt` and retained beside the source.
