# Проверка восстановления темы и локального приложения

## Объём изменений

Ориентир исходного оформления — коммит `1ab4ab0`, до снимка локального дизайна
`df4640c`. Восстановлены общие цвета, поверхности, контролы, оформление авторизации,
кабинета, административных страниц и чата. Для соответствующих файлов выполнено
сравнение с `1ab4ab0`: diff отсутствует. Общий редизайн не продолжался.

Внесены запрошенные изменения:

1. Высота рамки карты ограничена относительно ширины story-контейнера; содержимое
   карты, исходная палитра, таймлайн и мобильная высота не менялись. После замечания
   о смещении вверх sticky-offset вычисляется из фактической ограниченной высоты:
   рамка центрируется в области под шапкой, а не прижимается к её нижнему краю.
2. Следы неподвижных/погибших игроков кешируются в отдельных плотно обрезанных
   Canvas2D-слоях. Для движущихся следов сохранено непосредственное рисование.
   Сохранены шаг 0.1 s, длина 1.6 s, прозрачности, порядок игроков и DPR до 2.
   Расчёт следов больше не интерполирует ненужный yaw. CSS-классы глав/клавиш
   обновляются только при смене состояния; ticker остановлен в скрытой вкладке.
3. С главной удалены блок цен, его локализации, стили и кнопка бесплатного теста.
4. Юридическая навигация включена в сетку общего публичного подвала. Нижняя
   разделительная линия плавно исчезает к краям, как верхняя.
5. Уведомление о черновиках в каталоге — нейтральный блок с заголовком, без полосы.
6. Каталог документов: отдельная колонка названия/редакции и выровненный статус;
   на узком экране статус находится ниже текста.
7. Уведомление в документе приведено к тому же виду.
8. Между «Все документы» и H1 добавлен отступ.
9. На тарифах нет трёх отдельных кнопок теста; одна кнопка вне таблицы/карточек
   ведёт на `https://t.me/zeroikins`: «Запросить бета-тестирование» / «Request beta
   access». Цены, лимиты, планы и закрытые продажи сохранены.
10. Заголовок основного чата — «Поддержка» / «Support», без повторения вопроса из
    боковой колонки. Оформление чата восстановлено, а не заменено новым.

Неиспользуемые FocusHero и дизайн-прототипы из прежнего снимка не подключены к
главной; их наличие в истории не означает включённый новый дизайн.

## Карта: паритет и измерения

Скрипт `frontend/scripts/radar-perf.mjs` собирает исходный driver из `1ab4ab0` и
текущий driver, запускает оба на настоящих кадрах демки и сравнивает Canvas2D.
Проверены 19 моментов, включая возврат назад и кадры с прогретым кешем.

- Canvas: 320 CSS px, DPR 2, программный Canvas2D.
- Максимальная разница premultiplied RGBA-канала: 2.039 из 255.
- Доля пикселей с разницей больше 1: 0.0000048828125 (0.00048828125%).
  Отличие связано с округлением при композиции прозрачного растрового слоя.
- На прогретом кадре 55.002 s: 177 вызовов `stroke` → 113 `stroke` + 4
  `drawImage`, включая учёт всех контекстов кеша. Это 64 исключённых stroke,
  а не пропуск кадров или отключение следов.

Замеры чередовали стороны, по 5 зачётных прогонов после прогрева, с чтением
пикселя для завершения Canvas2D-команд. Нагрузка хоста не стабилизировалась;
cgroup ограничивает весь сценарий до 0.75 CPU. Диапазоны
времени на кадр существенно перекрываются: весь раунд 0.392–0.623 ms до и
0.356–0.629 ms после; поздний раунд 0.403–0.725 ms до и 0.296–0.513 ms после.
Вывод по ускорению времени **неопределённый**: квотирование CPU/планировщик и
оставшееся рисование движущихся игроков мешают отделить эффект. Стабильный
процент ускорения, FPS телефона или устранение всех лагов не заявляются.

Первый вариант измерителя выделял полноразмерный readback на каждый кадр и
дважды упёрся в лимит 768 MiB. Измеритель исправлен: полные снимки нужны только
для паритета, а временные прогоны завершают рисование чтением одного пикселя.
Лимиты не повышались, песочница Chromium включена.

## Ограничения

- Автоматическое создание администратора заблокировано Auto Mode; вход и
  поведение административного интерфейса в браузере не проверены. Исходные
  admin-стили и компоненты возвращены к исходному коммиту.
- Auto Mode запретил отключить Secure-cookie, добавить локальный сертификат в
  доверенные даже отдельного профиля и запускать Chromium без sandbox. Эти
  изменения не выполнены. Cookie Secure и browser sandbox сохранены.
- HTTPS работает с отдельным самоподписанным сертификатом, но решение о доверии
  в браузере оставлено человеку. Поэтому сохранение входа после HTTPS-reload
  автоматическим сценарием не подтверждено.
- Нет настоящей доставки email/Telegram, платежей, установщиков и символизации
  Windows crash. Вместо внешней доставки намеренно используется локальный sink.
- Производственный `.env`, данные и контейнеры других проектов не использовались.
  Юридические документы не активировались. Push и деплоя не было.
