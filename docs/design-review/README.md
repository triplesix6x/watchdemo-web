# WatchDemo: три визуальных направления

Изолированные статические исследования. Не новая версия сайта или приложения. Решения и ограничения: ../../DESIGN.md.

## Смотреть

Из корня репозитория:

```bash
python3 -m http.server 4401 --bind 127.0.0.1 --directory docs/design-review
```

Открыть http://127.0.0.1:4401/. A/B/C имеют отдельные страницы, адаптированную мобильную композицию, цветовой desktop-эскиз и возможность раскрыть неизменённый оригинал.

## Воспроизвести

Требуются уже установленные frontend/node_modules и Python Pillow.

```bash
python3 docs/design-review/build.py
# Запустить сервер командой выше, затем:
node docs/design-review/qa.mjs
```

Браузер: установленный /opt/google/chrome/chrome, sandbox включён. QA использует существующие playwright-core и axe-core, новых npm-зависимостей нет. Скриншоты и JSON отчёт находятся в shots/. Сначала генератор создаёт страницы и ассеты, затем QA создаёт скриншоты, которые индекс использует для превью.

## Материалы

- original.webp: точная копия исходного frontend/public/screens/app-home.webp.
- desktop-{a,b,c}.webp: непрерывное изменение палитры этого изображения, без изменения текста, матчей, расположения элементов. Это эскиз, не рендер модифицированной сборки.
- mobile-{a,b,c}.webp: кадрирование того же изображения на рабочую область. Недостающие края доступны горизонтальной прокруткой внутри figure, в том числе с клавиатуры.
- Onest: локальные существующие fontsource-файлы, семейство не меняется.
- logo.svg: исходный символ приложения, белый через CSS-фильтр для тёмного фона.
- terrain.svg: статическое контурное исследование, процедурно созданное marching-squares из гладкого поля. Не ReactBits Topography, не её реализация и не отказ от согласованной интерактивности. Нужен только для выбора плотности и композиции.

Живой рельеф, жесты, GSAP, скролл-история, загрузка приложения, видео CS2 и native не реализуются в этих исследованиях. Все ссылки в макетах локальные; CTA намеренно открывает пояснение, а не скачивает файл. Никаких внешних API и production-запросов.

## Проверка

Два полных прохода с дополнительным финальным после улучшения мобильной композиции. Последний отчёт: 15 сочетаний трёх концептов и ширин 375/390/820/1280/1440, три reduced-motion/keyboard-проверки, страница обзора, всего 19 записей. Нет горизонтального переполнения страницы, сломанных изображений, HTTP/page-errors или нарушений axe в проверенных WCAG2A/AA/2.1AA. Исправлен focusability горизонтальной области изображения. Проверено загруженное семейство Onest.

Это не production-аудит готового сайта и не оценка Awwwards. Производительность будущего WebGL, анимации, SEO готовых роутов и полный контраст desktop-состояний этими статическими исследованиями не доказаны. Оценки качества готового сайта не назначались. Исходные tracked-файлы обоих продуктов остались без изменений.
