Как смотреть

Откройте каждый вариант на компьютере и телефоне. Ниже первого экрана есть цветовой макет desktop и исходный скриншот для сравнения. Вариант B рекомендован как наиболее цельное представление всех инструментов, но выбирать можно любой.

Это статические исследования, не интерактивные прототипы. Здесь нет живой Topography, видео CS2 и настоящего скачивания. Их реализация начнётся после выбора направления.
