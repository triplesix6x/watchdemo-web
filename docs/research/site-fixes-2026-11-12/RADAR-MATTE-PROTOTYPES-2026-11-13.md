## B. Живое GPU-размытие

URL: <https://172.21.0.7:8443/__home-matte-20261113-v2/matte-live/index.html>

Индикатор: `LOCAL: matte-live ACTIVE`.

В корпус встроен отдельный низкоразрешённый экземпляр той же симуляции GhostFibers. Его настоящая scene texture проходит горизонтальный и вертикальный девятиточечные Gaussian passes, затем тонирование и вывод. Самая длинная сторона render target ограничена 320 физическими пикселями. Ограничение относится только к декоративной копии под картой, не к миникарте или основному фону страницы.

**Это действительно размываемая живая графика, но не точный захват DOM за корпусом.** Декоративная копия симулируется отдельно: её рисунок и фаза не обязаны совпадать с внешним фоном. Текст, карта и произвольные соседние элементы в blur не попадают. Таким образом избегаем CSS backdrop capture и покадрового GPU→CPU readback.

Для этого экземпляра отключена исходная bloom chain. Наблюдаются четыре instanced draws сцены и три fullscreen draws на кадр: два blur passes и composite. Есть дополнительный WebGL context; это не бесплатный эффект и не доказательство равной стоимости со статической текстурой.

При reduced-motion/transparency/contrast и forced colors живая копия не монтируется. Статическая текстура остаётся под ней. Контекст создаётся лениво, сохраняется при невидимости; собственный IntersectionObserver останавливает rendering. После потери контекста текстура также остаётся доступной.

Два разрешённых файла агента:

- `frontend/src/features/backgrounds/GhostFibers/GhostFibers.tsx` — необязательный matte mode, targets/shaders/cleanup;

В основное дерево эти два экспериментальных компонента не перенесены. Vite перенаправляет их только в live-варианте. Worktree использует символьную ссылку на существующие `frontend/node_modules`; зависимости не устанавливались.

Сборщик создаёт только свежий каталог. Уже существующий URL молча не перезаписывается. Обычная production-сборка удалит временные каталоги в `dist`; перед такой сборкой нужно сохранить выбранный preview либо снова создать его из исходников с новым именем каталога.

### Исправленные ошибки проверок

Первая версия preview не показывала текстуру: поздний CSS `background` равной специфичности сбрасывал `background-image`. Исправлена специфичность локального selector; для исправления создан новый URL `v2`, а не подменён проверяемый bundle.

Изначальная lifecycle-проверка неверно ожидала, что sticky-корпус полностью уйдёт за экран при прокрутке до конца документа. Измерено: на desktop его нижняя граница остаётся на 666 px, на mobile — на 176 px. Это не ошибка renderer и не утечка: видимая часть имеет право рисоваться. Для узкой проверки IntersectionObserver тест явно переносит только декоративный контейнер за viewport временным QA-transform, подтверждает ноль новых кадров, затем возвращает его и проверяет тот же context без перекомпиляции/аллокаций. Это контролируемая проверка видимости, а не утверждение о естественном offscreen scroll.
